# InfoSihat

Maklumat Kesihatan dihujung Jari · Health information at your fingertips.

Bilingual (Bahasa Melayu Brunei and English) eye-health information for Brunei, written by doctors. Project lead: Dr Haziq Aziz Shamri, Ophthalmology Resident, Brunei Eye Centre.

This repository is the published website (GitHub Pages). Content is for general education and does not replace medical advice.
